# Ntokazi Catering & Events — Website

This is a responsive static website built for Ntokazi Catering & Events.

## Files
- index.html — website structure/content
- style.css — design/responsive layout
- script.js — mobile menu, year and enquiry form
- assets/ntokazi-logo.png — extracted from the supplied logo PDF

## Before publishing
1. Contact numbers and business email are already configured.
2. Replace the gallery placeholders with real food/event photographs when available.
4. Publish the folder using GitHub Pages or another static host that supports a custom domain.

## Custom domain
The domain `ntokazicatering.co.za` can be configured at the domain/DNS provider to point to the chosen static host. Do not change nameservers or DNS records until the hosting provider gives the exact records required.

## Content basis
Business history and positioning are based on the information supplied by the client.
